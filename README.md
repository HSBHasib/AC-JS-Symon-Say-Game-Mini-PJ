# Simon Says Game

A classic, interactive, and memory-testing web game built using pure **Vanilla JavaScript**, **HTML5**, and **CSS3**.  
Test your memory limits by tracking and replicating ever-increasing randomized flash sequences!

## About the Project

This **Simon Says Game** is a lightweight, logic-based mini-game designed to test and improve cognitive memory. The game generates a random sequence of button flashes, and the player must replicate the exact sequence by clicking the colorful buttons in the correct order. With each successful round, the game levels up, increasing the sequence length and difficulty.

* **State Management:** Local Arrays for Game & User sequences

---

## 📦 Project Structure

* `index.html` - Contains the primary semantic structure and button elements.
* `script.js` - Handles game state, randomized index tracking, sequence validation, and flash intervals.
* `style.css` - Contains look-and-feel variables, layout configurations, and custom visual filters.
* `responsive.css` - Manages cross-device viewports for tablets and mobile devices.

---

## 🚀 Key Features

### 🔀 Dynamic Sequence Generation
* Automatically picks a random button using a random index generator every time the player advances to the next level.

### ⚡ Visual Flash Cues
* Features system-guided automatic flashes to show the sequence, and custom color changes when a player clicks a button.

### 🧠 Real-Time Sequence Matching
* Runs a continuous verification check to ensure the player matches the exact game sequence step-by-step.

### 🛑 Game Over Screen & Quick Reset
* Turns the background red instantly on a wrong button press, displays the final score, and resets all data so the player can restart immediately.
